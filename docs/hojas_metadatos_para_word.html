Resumen (Abstract):
El presente proyecto de investigación se centra en el desarrollo de un sistema predictivo basado en Machine Learning (CASSERISISSIMA 2.0) para optimizar la gestión de inventarios perecederos en la Pastelería Casseríssimas, ubicada en Maturín, Estado Monagas. Para ello, se aplicó una metodología de investigación proyectiva y de campo, orientada a diagnosticar los flujos de inventario actuales y diseñar un modelo de ensamble algorítmico (Random Forest y LightGBM) capaz de pronosticar la demanda con alta precisión y mitigar el riesgo de quiebres de stock. La solución se materializó mediante el desarrollo de una arquitectura de software Cliente-Servidor (FastAPI, Next.js, SQLite) que integra el modelo predictivo con la fórmula del Punto de Reorden Evolutivo, determinando dinámicamente las cantidades óptimas de producción (modelo Newsvendor). Se espera que la implementación de este sistema tecnológico y su respectivo tablero de control gerencial generen un impacto económico altamente positivo, evidenciado en la simulación retrospectiva (Backtesting) mediante la erradicación de las mermas por caducidad (100%) y la reducción significativa de las ventas perdidas (71.1%), impulsando así la transición organizacional hacia la toma de decisiones basada en datos bajo un enfoque "Human-First".
